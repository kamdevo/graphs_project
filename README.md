
# Graphs generator built with python 
App built with python that reads, processes and illustrates graphs from CSV/TXT edge list files. Final project for Discrete mathematics II.

## Graph representation
The representation we decided to approach is the Adjacency List representation which consists of storing a graph by containing a list of neighbors for every single node.
for its simple approach that is easy to familiarize with.
